# 02. 旧試験 AZ-204 から AI-200 への変更点

AZ-204（Developing Solutions for Microsoft Azure）は **2026-07-31** に廃止され、AI-200 が後継になりました。
単なる名前の変更ではなく、**「Azure PaaS 開発者」から「AI アプリの基盤を作る開発者」**へ中身が組み替えられています。

## 1. AZ-204 の最終版の出題範囲（2026-01-14 版、公式スタディガイドより）

| AZ-204 の分野 | 配点 | 主な内容（公式の項目） |
|---|---|---|
| Develop Azure compute solutions | 25–30% | コンテナイメージの作成・ACR への発行・**ACI での実行**・Container Apps / App Service Web Apps（作成、診断とログ、コードとコンテナのデプロイ、TLS・API 設定、**自動スケール**、**デプロイスロット**）/ Azure Functions（作成と構成、入出力バインド、データ操作・タイマー・Webhook のトリガー） |
| Develop for Azure storage | 15–20% | Cosmos DB（SDK でのコンテナとアイテムの操作、整合性レベル、変更フィード）/ **Blob Storage**（プロパティとメタデータ、SDK 操作、ストレージポリシーとライフサイクル管理） |
| Implement Azure security | 15–20% | **Microsoft Identity Platform**、Entra ID による認証・認可、**SAS**、**Microsoft Graph** / App Configuration・Key Vault（キー・シークレット・証明書）、マネージド ID |
| Monitor and troubleshoot Azure solutions | 5–10% | Azure Monitor Application Insights（メトリック・ログ・トレース、**可用性テスト**とアラート、アプリの計装） |
| Connect to and consume Azure services and third-party services | 20–25% | **API Management**（インスタンス作成、API の作成と文書化、アクセス構成、ポリシー）/ Event Grid、**Event Hubs** / Service Bus、**Queue Storage** |

太字は AI-200 で範囲から外れたものです。

## 3. 考え方の 3 つの変化

1. **ストレージの主役が Blob からベクトル DB へ。**
   RAG（検索拡張生成）の検索部分を担う Cosmos DB / PostgreSQL / Redis の 3 つを、要件で使い分けられることが求められます。
2. **AKS が開発者の範囲に入った。**
   GPU ノードプールや細かなリソース制御が必要な AI ワークロードは、Container Apps だけでは足りないことがあるためです。
   開発者として「マニフェストを書いてデプロイし、kubectl で原因を調べる」レベルが問われます（クラスター設計や運用は範囲外）。
3. **計装がベンダー独自 SDK から OpenTelemetry へ。**
   Application Insights は受け皿（バックエンド）として残り、計装は OpenTelemetry の標準 API で行います。

## 4. 立場別の進め方

### AZ-204 合格者・経験者

- 引き継げる範囲（Functions、Service Bus、Event Grid、Key Vault、App Configuration、Container Apps、Cosmos DB の基本）は**復習だけ**でよい。ただし 2026 年時点の仕様（Flex Consumption、Functions の isolated worker モデル、Event Grid の CloudEvents など）に更新しておく。
- 重点を置くのは次の 4 つ:
  1. **AKS**（マニフェスト、Service、ConfigMap / Secret、PVC、プローブ、kubectl でのトラブルシュート）
  2. **PostgreSQL + pgvector**（演算子、HNSW / IVFFlat、メタデータフィルター、PgBouncer）
  3. **Azure Managed Redis**（Azure Cache for Redis との違い、RediSearch、クラスタリングポリシー）
  4. **OpenTelemetry と KQL**
- 目安: 新しい範囲に 3〜4 週間、引き継ぎ範囲の復習に 1 週間。

### これから始める人

- AZ-204 の教材を使う必要はありません。AI-200 のラーニングパス 9 本と本リポジトリの分野ノートで進めてください。
- 古い AZ-204 向けの問題集には、範囲外（Blob、APIM、Graph など）の問題が多く含まれるので注意が必要です。

### AZ-204 の認定を持っている人の更新

- 取得済みの AZ-204 認定は有効期限まで有効です。
- 更新期間が AZ-204 の廃止後に来る場合は、AZ-204 の更新評価が受けられない可能性があるため、AI-200 の取得を検討してください（具体的な扱いは公式の更新 FAQ で確認）。
